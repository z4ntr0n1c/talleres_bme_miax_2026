3. Modelado: DataClass PriceSeries

En src/toolkit/models/series.py, cálculo automático de retorno medio y desviación típica:

@dataclass
class PriceSeries:
    ticker: str
    asset_type: str
    data: pd.DataFrame
    mean_return: float = field(init=False)
    std_return: float = field(init=False)

    def __post_init__(self):
        if "close" not in self.data.columns:
            raise ValueError("Los datos deben incluir una columna 'close'.")
        if "returns" not in self.data.columns:
            self.data["returns"] = self.data["close"].pct_change()
        clean = self.data["returns"].dropna()
        self.mean_return = float(clean.mean()) if not clean.empty else 0.0
        self.std_return = float(clean.std()) if not clean.empty else 0.0
