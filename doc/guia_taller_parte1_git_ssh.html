Taller B1-T1: Control de Versiones y Claves SSH

MIAX - BME | Inicialización de Repositorio Local y Autenticación Criptográfica con GitHub

1. Inicialización del Repositorio Local

Accede al directorio del proyecto en tu máquina local e inicializa la rama principal con la nomenclatura estándar main:

cd /home/sergio/Documents/Master_MIAX_BME/Talleres_Master_MIAX_BME/T1
git init -b main

2. Generación del Par de Claves SSH (Ed25519)

Genera una clave criptográfica moderna y segura asociada a la cuenta de GitHub:

ssh-keygen -t ed25519 -C "tu_correo@ejemplo.com"

Pulsa Enter para aceptar la ruta predeterminada (~/.ssh/id_ed25519) y define opcionalmente una contraseña de paso.

3. Activación del Agente SSH y Registro de la Clave

Inicia el agente SSH en segundo plano y añade la clave privada recién creada:

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

4. Vinculación de la Clave Pública en GitHub

  1. Copia el contenido completo de la clave pública: 
    cat ~/.ssh/id_ed25519.pub
  2. En GitHub, dirígete a Settings > SSH and GPG keys > New SSH key.
  3. Asigna un título identificativo (p. ej., Portátil Dell Linux) y pega la clave pública.

5. Verificación de Autenticación

Prueba de conexión con los servidores de GitHub desde la terminal:

$ ssh -T git@github.com Hi z4ntr0n1c! You've successfully authenticated, but GitHub does not provide shell access.

6. Configuración del Repositorio Remoto

Asocia el repositorio local a la URL de SSH para realizar operaciones remotas sin ingresar credenciales manualmente:

git remote add origin git@github.com:z4ntr0n1c/talleres_bme_miax_2026.git
git add .
git commit -m "Initial commit"
git push -u origin main
