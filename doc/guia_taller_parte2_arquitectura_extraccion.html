3. Ingesta Multifuente Estandarizada y PriceSeries (Requisitos 4.2 y 4.3)

Todos los conectores heredan de BaseDataExtractor (YahooFinanceExtractor para renta variable e índices bursátiles, y FREDExtractor para series macroeconómicas de la Reserva Federal con fallback automático a fredgraph.csv) y normalizan sus salidas mediante _normalize_close_dataframe() al esquema canónico ["close", "returns"] dentro de PriceSeries:

@dataclass
class PriceSeries:
    ticker: str
    asset_type: str
    data: pd.DataFrame
    mean_return: float = field(init=False)
    std_return: float = field(init=False)

    def __post_init__(self) -> None:
        if "close" not in self.data.columns:
            raise ValueError("Input data must contain a 'close' column.")
        self.ticker = self.ticker.strip().upper()
        self.data = self.data.copy()  # Copia defensiva sin mutar la entrada
        if "returns" not in self.data.columns:
            self.data["returns"] = self.data["close"].pct_change()
        clean_returns = self.returns
        self.mean_return = float(clean_returns.mean()) if not clean_returns.empty else 0.0
        self.std_return = float(clean_returns.std()) if not clean_returns.empty else 0.0
